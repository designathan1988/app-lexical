# ARQUITETURA CANÔNICA DO COMPILADOR SEMÂNTICO

## 1. Pipeline definitivo

```text
RAW INPUT
   │
   ▼
NON-DESTRUCTIVE LEXER
   │
   ├── WORD
   ├── STRING_LITERAL
   ├── NUMBER
   ├── CSS_UNIT
   ├── COLOR_HEX
   └── PUNCTUATION
   │
   ▼
GRAMMATICAL NORMALIZER
   │
   ├── Unicode normalization
   ├── Portuguese contractions
   └── token boundaries preserved
   │
   ▼
MULTIWORD MATCHER
   │
   └── Trie / longest match
   │
   ▼
LEXICAL RESOLUTION
   │
   ├── exact SurfaceForm candidates
   ├── Lexeme candidates
   ├── Concept/Sense candidates
   └── phonetic candidates only as fallback
   │
   ▼
DOMAIN PARSER
   │
   ├── action scope
   ├── noun/entity phrases
   ├── property/value phrases
   ├── coordination
   ├── containment
   ├── spatial relations
   ├── quantification
   ├── negation
   └── reference expressions
   │
   ▼
SEMANTIC AST
   │
   ▼
WORD-SENSE + PROPERTY BINDING
   │
   ▼
DOCUMENT REFERENCE RESOLVER
   │
   ▼
CONSTRAINT VALIDATOR
   │
   ▼
EXECUTION PLANNER
   │
   ▼
EXECUTION PLAN
   │
   ▼
OPERATION-SPECIFIC EXECUTOR
   ├── CREATE
   ├── UPDATE
   ├── DELETE
   ├── MOVE
   └── QUERY
```

A regra estrutural é:

```text
SurfaceForm ≠ Lexeme
Lexeme ≠ Concept
Concept ≠ Mention
Mention ≠ DocumentInstance
SemanticAST ≠ ExecutionPlan
ExecutionPlan ≠ RuntimeMutation
```

# 3. Camada lexical

## 3.1 SurfaceForm

Uma forma escrita representa somente uma ocorrência lexical reconhecível.

Ela não carrega significado de runtime.

```ts
export interface SurfaceForm {
  id: SurfaceFormId;

  rawText: string;

  lexemeId: LexemeId;

  formType:
    | 'CANONICAL'
    | 'INFLECTION'
    | 'COLLOQUIAL'
    | 'MISSPELLING'
    | 'ABBREVIATION';

  morphology?: Morphology;
}
```

Campos derivados como `searchKey` e `phoneticKey` não são persistidos obrigatoriamente.

São índices calculados durante a inicialização.

## 4.4 PropertyGroupConcept

Isto resolve corretamente termos como `borda`.

`borda` não precisa significar diretamente `borderColor` nem `borderWidth`.

```ts
export interface PropertyGroupConcept {
  kind: 'PROPERTY_GROUP';

  id: ConceptId;

  members: ConceptId[];

  bindingByValueCategory:
    Partial<Record<ValueCategory, ConceptId>>;

  clearPropertyIds: ConceptId[];
}
```

Exemplo:

```ts
const BORDER_GROUP: PropertyGroupConcept = {
  kind: 'PROPERTY_GROUP',

  id: 'C_PROP_GROUP_BORDER',

  members: [
    'C_PROP_BORDER_COLOR',
    'C_PROP_BORDER_WIDTH',
    'C_PROP_BORDER_STYLE'
  ],

  bindingByValueCategory: {
    COLOR: 'C_PROP_BORDER_COLOR',
    SIZE: 'C_PROP_BORDER_WIDTH',
    ENUM: 'C_PROP_BORDER_STYLE'
  },

  clearPropertyIds: [
    'C_PROP_BORDER_COLOR',
    'C_PROP_BORDER_WIDTH',
    'C_PROP_BORDER_STYLE'
  ]
};
```

Portanto:

```text
borda azul
→ COLOR
→ borderColor

borda 2px
→ SIZE
→ borderWidth

sem borda
→ CLEAR C_PROP_GROUP_BORDER
```

# 9. Lexer não destrutivo

```ts
export type RawTokenType =
  | 'WORD'
  | 'STRING'
  | 'NUMBER'
  | 'CSS_UNIT'
  | 'COLOR_HEX'
  | 'PUNCT';

export interface RawToken {
  type: RawTokenType;

  raw: string;

  normalized?: string;

  start: number;

  end: number;

  value?: string | number;

  unit?: string;
}

export class RawLexer {
  static normalize(text: string): string {
    return text
      .normalize('NFD')
      .replace(/\p{M}/gu, '')
      .toLowerCase();
  }

  lex(input: string): RawToken[] {
    const tokens: RawToken[] = [];

    let i = 0;

    while (i < input.length) {
      const char = input[i];

      if (/\s/u.test(char)) {
        i++;
        continue;
      }

      const rest = input.slice(i);

      if (char === '"' || char === "'") {
        const quote = char;

        let j = i + 1;
        let escaped = false;

        while (j < input.length) {
          if (!escaped && input[j] === quote) {
            break;
          }

          escaped =
            !escaped &&
            input[j] === '\\';

          if (input[j] !== '\\') {
            escaped = false;
          }

          j++;
        }

        const close =
          j < input.length
            ? j
            : input.length - 1;

        const raw =
          input.slice(i, close + 1);

        const value =
          input.slice(i + 1, close);

        tokens.push({
          type: 'STRING',
          raw,
          value,
          start: i,
          end: close + 1
        });

        i = close + 1;
        continue;
      }

      const hex =
        rest.match(/^#[0-9a-fA-F]{3,8}(?![0-9a-fA-F])/);

      if (hex) {
        tokens.push({
          type: 'COLOR_HEX',
          raw: hex[0],
          value: hex[0],
          start: i,
          end: i + hex[0].length
        });

        i += hex[0].length;
        continue;
      }

      const unit =
        rest.match(
          /^-?(?:\d+(?:\.\d+)?|\.\d+)(px|rem|em|%|vh|vw|vmin|vmax|ch|ex)\b/i
        );

      if (unit) {
        const amount =
          Number.parseFloat(unit[0]);

        tokens.push({
          type: 'CSS_UNIT',
          raw: unit[0],
          value: amount,
          unit: unit[1].toLowerCase(),
          start: i,
          end: i + unit[0].length
        });

        i += unit[0].length;
        continue;
      }

      const number =
        rest.match(
          /^-?(?:\d+(?:\.\d+)?|\.\d+)/
        );

      if (number) {
        tokens.push({
          type: 'NUMBER',
          raw: number[0],
          value:
            Number.parseFloat(number[0]),
          start: i,
          end: i + number[0].length
        });

        i += number[0].length;
        continue;
      }

      const word =
        rest.match(
          /^[\p{L}\p{M}][\p{L}\p{M}\d_-]*/u
        );

      if (word) {
        tokens.push({
          type: 'WORD',
          raw: word[0],
          normalized:
            RawLexer.normalize(word[0]),
          start: i,
          end: i + word[0].length
        });

        i += word[0].length;
        continue;
      }

      tokens.push({
        type: 'PUNCT',
        raw: char,
        value: char,
        start: i,
        end: i + 1
      });

      i++;
    }

    return tokens;
  }
}
```

```ts
  tokens: RawToken[]

      token.type !== 'WORD' ||
      !token.normalized
```

# 11. Trie verdadeiro para expressões multiword

```ts
interface TrieNode {
  children: Map<string, TrieNode>;
  entry?: MultiwordEntry;
}

export class MultiwordTrie {
  private root: TrieNode = {
    children: new Map()
  };

  constructor(entries: MultiwordEntry[]) {
    for (const entry of entries) {
      this.insert(entry);
    }
  }

  private insert(entry: MultiwordEntry): void {
    const parts =
      RawLexer
        .normalize(entry.phrase)
        .split(/\s+/);

    let node = this.root;

    for (const part of parts) {
      let child =
        node.children.get(part);

      if (!child) {
        child = {
          children: new Map()
        };

        node.children.set(
          part,
          child
        );
      }

      node = child;
    }

    node.entry = entry;
  }

  match(
    tokens: RawToken[],
    start: number
  ): {
    entry: MultiwordEntry;
    length: number;
  } | null {
    let node = this.root;

    let best:
      | {
          entry: MultiwordEntry;
          length: number;
        }
      | null = null;

    for (
      let i = start;
      i < tokens.length;
      i++
    ) {
      const token = tokens[i];

      if (
        token.type !== 'WORD' ||
        !token.normalized
      ) {
        break;
      }

      const child =
        node.children.get(
          token.normalized
        );

      if (!child) {
        break;
      }

      node = child;

      if (node.entry) {
        best = {
          entry: node.entry,
          length: i - start + 1
        };
      }
    }

    return best;
  }
}
```

```ts
export class PortuguesePhonetic {
  static key(input: string): string {
    let s =
      RawLexer.normalize(input);

    s = s
      .replace(/nh/g, 'N')
      .replace(/lh/g, 'L')
      .replace(/ch/g, 'X')
      .replace(/sh/g, 'X')
      .replace(/ph/g, 'F');

    s = s
      .replace(/qu(?=[ei])/g, 'K')
      .replace(/gu(?=[ei])/g, 'G');

    s = s
      .replace(/ç/g, 's')
      .replace(/c(?=[ei])/g, 's')
      .replace(/c/g, 'k')
      .replace(/q/g, 'k')
      .replace(/z/g, 's')
      .replace(/x/g, 's')
      .replace(/g(?=[ei])/g, 'j')
      .replace(/h/g, '');

    s = s
      .replace(/[aeiou]+/g, 'A')
      .replace(/(.)\1+/g, '$1');

    return s.toUpperCase();
  }
}
```

```ts
    for (
      const surface

      const normalized =
        RawLexer.normalize(
          surface.rawText

      const exactBucket =
        this.exact.get(normalized) ?? [];

      this.exact.set(
        normalized,
        exactBucket
      );

      const phoneticKey =
        PortuguesePhonetic.key(
          surface.rawText
        );

      const phoneticBucket =
        this.phonetic.get(
          phoneticKey
        ) ?? [];

      phoneticBucket.push(surface);

      this.phonetic.set(
        phoneticKey,
        phoneticBucket
      );
    }

    raw: string
  ): SurfaceCandidate[] {
    const normalized =
      RawLexer.normalize(raw);

    const exactMatches =
      this.exact.get(normalized);

    if (exactMatches?.length) {
      return exactMatches
        .map(surface => ({
          surfaceForm: surface,

          lexeme:
            this.lexemes[
              surface.lexemeId
            ],

          source: 'EXACT' as const,

          score:
            surface.formType ===
            'CANONICAL'
              ? 1
              : 0.98

        .filter(x => x.lexeme);
    }

    const phonetic =
      PortuguesePhonetic.key(raw);

    return (
      this.phonetic.get(

    )

        surfaceForm: surface,

        lexeme:
          this.lexemes[
            surface.lexemeId
```

```ts
export class SemanticTokenBuilder {
  constructor(
    private concepts:
      Record<ConceptId, ConceptNode>,

      LexicalIndex,

    private trie:
      MultiwordTrie
  ) {}

  build(
    tokens: RawToken[]
  ): SemanticToken[] {

      SemanticToken[] = [];

    for (
      let i = 0;
      i < tokens.length;
    ) {
      const token = tokens[i];

      const mwe =
        this.trie.match(
          tokens,
          i
        );

      if (mwe) {
        output.push({
          rawTokens:
            tokens.slice(
              i,
              i + mwe.length
            ),

          candidates: [
            {
              conceptId:
                mwe.entry.conceptId,

              score: 1,

              source:
                'MULTIWORD'
            }
          ]

        i += mwe.length;
        continue;
      }

      if (
        token.type === 'STRING'

          candidates: [],

            kind: 'TEXT',
            value:
              String(token.value)
          }
        });

        i++;
        continue;
      }

      if (
        token.type ===
        'COLOR_HEX'
      ) {
        output.push({
          rawTokens: [token],
          candidates: [],
          literal: {
            kind: 'COLOR',
            value:
              String(token.value)
          }
        });

        i++;
        continue;
      }

      if (
        token.type ===
        'CSS_UNIT'
      ) {
        output.push({
          rawTokens: [token],
          candidates: [],
          literal: {
            kind: 'SIZE',
            value:
              Number(token.value),
            unit:
              token.unit!
          }
        });

        i++;
        continue;
      }

      if (
        token.type === 'NUMBER'
      ) {
        output.push({
          rawTokens: [token],
          candidates: [],
          literal: {
            kind: 'NUMBER',
            value:
              Number(token.value)
          }
        });

        i++;
        continue;
      }

      if (
        token.type === 'WORD'
      ) {
        const lexical =
          this.lexicalIndex.resolve(
            token.raw
          );

        const candidates:
          ConceptCandidate[] = [];

        for (
          const candidate
          of lexical
        ) {
          for (
            const conceptId
            of candidate.lexeme
              .senseConceptIds
          ) {
            if (
              this.concepts[
                conceptId

              candidates.push({
                conceptId,
                lexemeId:
                  candidate.lexeme.id,
                score:
                  candidate.score,
                source:
                  candidate.source
              });
            }
          }
        }

        output.push({
          rawTokens: [token],
          candidates
        });

        i++;
        continue;
      }

      output.push({
        rawTokens: [token],
        candidates: []
      });

      i++;
    }
```

# 19. SemanticCursor

```ts
class SemanticCursor {
  index = 0;

  constructor(
    public tokens:
      SemanticToken[]
  ) {}

  eof(): boolean {
    return (
      this.index >=
      this.tokens.length
    );
  }

  peek(
    offset = 0
  ): SemanticToken | undefined {
    return this.tokens[
      this.index + offset
    ];
  }

  consume():
    SemanticToken | undefined {
    return this.tokens[
      this.index++
    ];
  }

  rawWord(
    offset = 0
  ): string | null {
    const token =
      this.peek(offset);

    if (!token) {
      return null;
    }

    const raw =
      token.rawTokens
        .map(x => x.raw)
        .join(' ');

    return RawLexer.normalize(
      raw
    );
  }

  consumeWord(
    expected: string
  ): boolean {
    if (
      this.rawWord() !==
      expected
    ) {
      return false;
    }

    this.consume();
    return true;
  }
}
```

```ts
export class PropertyBinder {
  constructor(
    private concepts:
      Record<
        ConceptId,
        ConceptNode
      >
  ) {}

  bind(
    entityConceptId:
      ConceptId | undefined,

    mutation:
      AstPropertyMutation
  ): AstPropertyMutation {
    if (
      mutation.kind ===
      'CLEAR'
    ) {
      return mutation;
    }

    if (
      mutation.propertyConceptId
    ) {
      const property =
        this.concepts[
          mutation
            .propertyConceptId
        ];

      if (
        property?.kind !==
        'PROPERTY'
      ) {
        throw new Error(
          `Unknown property ${mutation.propertyConceptId}`
        );
      }

      if (
        !property
          .valueCategories
          .includes(
            mutation
              .value
              .category
          )
      ) {
        throw new Error(
          `Property ${property.id} does not accept ${mutation.value.category}`
        );
      }

      return mutation;
    }

    if (
      mutation.propertyGroupId
    ) {
      const group =
        this.concepts[
          mutation
            .propertyGroupId
        ];

      if (
        group?.kind !==
        'PROPERTY_GROUP'
      ) {
        throw new Error(
          `Unknown property group ${mutation.propertyGroupId}`
        );
      }

      const propertyId =
        group
          .bindingByValueCategory[
            mutation
              .value
              .category
          ];

      if (!propertyId) {
        throw new Error(
          `Property group ${group.id} has no binding for ${mutation.value.category}`
        );
      }

      return {
        kind: 'SET',

        propertyConceptId:
          propertyId,

        value:
          mutation.value
      };
    }

    if (!entityConceptId) {
      throw new Error(
        'Cannot infer property without entity context'
      );
    }

    const entity =
      this.concepts[
        entityConceptId
      ];

    if (
      entity?.kind !==
      'ENTITY'
    ) {
      throw new Error(
        `Unknown entity ${entityConceptId}`
      );
    }

    const propertyId =
      entity
        .capabilities
        .defaultValueBindings[
          mutation
            .value
            .category
        ];

    if (!propertyId) {
      throw new Error(
        `Entity ${entity.id} has no default binding for ${mutation.value.category}`
      );
    }

    return {
      kind: 'SET',

      propertyConceptId:
        propertyId,

      value:
        mutation.value
    };
  }
```

```ts
      return null;
    }

    const chosen =
      candidates[0];

    cursor.consume();

    return chosen;
  }
```

O uso de `[0]` aqui é seguro somente porque o filtro já restringiu a um único domínio sintático `ACTION`.

Se dois sentidos verbais de ação continuarem possíveis, deve-se aplicar score contextual antes da escolha.

# 23. Determinantes, quantidade e ordinal

```ts
  private parseNominalPrefix(
    cursor:
      SemanticCursor
  ): {
    definiteness:
      | 'DEFINITE'
      | 'INDEFINITE'
      | 'UNSPECIFIED';

    quantity:
      | number
      | 'ALL'
      | null;

    ordinal:
      number | null;
  } {
    let definiteness:
      | 'DEFINITE'
      | 'INDEFINITE'
      | 'UNSPECIFIED' =
      'UNSPECIFIED';

    let quantity:
      | number
      | 'ALL'
      | null = null;

    let ordinal:
      number | null = null;

    const word =
      cursor.rawWord();

    if (
      word &&
      GRAMMAR
        .definiteArticles
        .has(word)
    ) {
      definiteness =
        'DEFINITE';

      cursor.consume();
    } else if (
      word &&
      GRAMMAR
        .indefiniteArticles
        .has(word)
    ) {
      definiteness =
        'INDEFINITE';

      cursor.consume();
    } else if (
      word &&
      GRAMMAR
        .all
        .has(word)
    ) {
      quantity =
        'ALL';

      definiteness =
        'DEFINITE';

      cursor.consume();

      const article =
        cursor.rawWord();

      if (
        article &&
        GRAMMAR
          .definiteArticles
          .has(article)
      ) {
        cursor.consume();
      }
    }

    const ordinalWord =
      cursor.rawWord();

    if (
      ordinalWord &&
      GRAMMAR
        .ordinals
        .has(
          ordinalWord
        )
    ) {
      ordinal =
        GRAMMAR
          .ordinals
          .get(
            ordinalWord
          )!;

      cursor.consume();
    }

    const literal =
      cursor.peek()
        ?.literal;

    if (
      literal?.kind ===
      'NUMBER'
    ) {
      quantity =
        Number(
          literal.value
        );

      cursor.consume();
    }

    return {
      definiteness,
      quantity,
      ordinal
    };
  }
```

```ts
  private parseValue(
    cursor:
      SemanticCursor
  ): AstValue | null {
    const token =
      cursor.peek();

    if (!token) {
      return null;
    }

    if (token.literal) {
      switch (
        token.literal.kind
      ) {
        case 'COLOR':
          cursor.consume();

          return {
            category: 'COLOR',
            literal:
              token.literal.value
          };

        case 'SIZE':
          cursor.consume();

          return {
            category: 'SIZE',

            literal:
              `${token.literal.value}${token.literal.unit}`
          };

        case 'NUMBER':
          cursor.consume();

          return {
            category: 'NUMBER',

            literal:
              token.literal.value
          };

        case 'TEXT':
          return null;
      }
    }

    const values =
      conceptsOfKind(
        token,
        this.concepts,
        'VALUE'
      );

    if (!values.length) {
      return null;
    }

    const value =
      values[0];

    cursor.consume();

    return {
      category:
        value.valueCategory,

      literal:
        value.literal
    };
```

# 27. Mutation parser

```ts
  private parseMutation(
    cursor:
      SemanticCursor,

    entityConceptId?:
      ConceptId
  ): AstPropertyMutation | null {
    const initialIndex =
      cursor.index;

    const raw =
      cursor.rawWord();

    if (
      raw === 'sem'
    ) {
      cursor.consume();

      const property =
        this.parsePropertyHead(
          cursor
        );

      if (!property) {
        cursor.index =
          initialIndex;

        return null;
      }

      return property.kind ===
        'PROPERTY'
        ? {
            kind: 'CLEAR',
            propertyConceptId:
              property.conceptId
          }
        : {
            kind: 'CLEAR',
            propertyGroupId:
              property.conceptId
          };
    }

    const explicitProperty =
      this.parsePropertyHead(
        cursor
      );

    if (
      explicitProperty
    ) {
      if (
        cursor.rawWord() ===
          'com' ||
        cursor.rawWord() ===
          'para' ||
        cursor.rawWord() ===
          'de'
      ) {
        cursor.consume();
      }

      const value =
        this.parseValue(
          cursor
        );

      if (!value) {
        cursor.index =
          initialIndex;

        return null;
      }

      const unresolved:
        AstPropertyMutation =
        explicitProperty.kind ===
          'PROPERTY'
          ? {
              kind: 'SET',
              propertyConceptId:
                explicitProperty
                  .conceptId,
              value
            }
          : {
              kind: 'SET',
              propertyGroupId:
                explicitProperty
                  .conceptId,
              value
            };

      return this
        .binder
        .bind(
          entityConceptId,
          unresolved
        );
    }

    const value =
      this.parseValue(
        cursor
      );

    if (value) {
      return this
        .binder
        .bind(
          entityConceptId,
          {
            kind: 'SET',
            value
          }
        );
    }

    cursor.index =
      initialIndex;

    return null;
  }
```

```ts
  private parseNewEntity(
    cursor:
      SemanticCursor
  ): NewEntityAst | null {
    const prefix =
      this.parseNominalPrefix(
        cursor
      );

    const head =
      this.parseEntityHead(
        cursor
      );

    if (!head) {
      return null;
    }

    const tempId =
      this.nextTempId();

    const entity:
      NewEntityAst = {
      tempId,

      entityConceptId:
        head.concept.id,

      quantity:
        typeof prefix.quantity ===
          'number'
          ? prefix.quantity
          : 1,

      mutations: []
    };

    const literal =
      cursor.peek()
        ?.literal;

    if (
      literal?.kind ===
      'TEXT'
    ) {
      entity.text =
        String(
          literal.value
        );

      cursor.consume();
    }

    while (
      !cursor.eof()
    ) {
      const before =
        cursor.index;

      const mutation =
        this.parseMutation(
          cursor,
          entity
            .entityConceptId
        );

      if (mutation) {
        entity.mutations.push(
          mutation
        );

        continue;
      }

      if (
        before ===
        cursor.index
      ) {
        break;
      }
    }

    this.discourse.add({
      reference: {
        kind:
          'NEW_ENTITY',
        tempId
      },

      entityConceptId:
        entity.entityConceptId,

      gender:
        head.gender,

      number:
        head.number
    });

    return entity;
  }
```

# 29. Selector parser

```ts
  private parseSelector(
    cursor:
      SemanticCursor,

    inheritedEntityConceptId?:
      ConceptId
  ): SemanticSelector {
    const prefix =
      this.parseNominalPrefix(
        cursor
      );

    let entityConceptId =
      inheritedEntityConceptId;

    const head =
      this.parseEntityHead(
        cursor
      );

    if (head) {
      entityConceptId =
        head.concept.id;
    }

    const selector:
      SemanticSelector = {
      entityConceptId,

      quantity:
        prefix.quantity ===
          'ALL'
          ? {
              mode: 'ALL'
            }
          : typeof prefix.quantity ===
              'number'
            ? {
                mode: 'COUNT',
                count:
                  prefix.quantity
              }
            : {
                mode: 'ONE'
              }
    };

    if (
      prefix.ordinal !==
      null
    ) {
      selector.ordinalIndex =
        prefix.ordinal;
    }

    const text =
      cursor.peek()
        ?.literal;

    if (
      text?.kind ===
      'TEXT'
    ) {
      selector.textEquals =
        String(
          text.value
        );

      cursor.consume();
    }

    if (
      GRAMMAR
        .except
        .has(
          cursor.rawWord() ?? ''
        )
    ) {
      cursor.consume();

      selector.exclusions = [
        this.parseSelector(
          cursor,
          entityConceptId
        )
      ];
    }

    return selector;
  }
```

# 32. CREATE parser

```ts
  private parseCreate(
    cursor:
      SemanticCursor
  ): CreateCommandAst {
    const entities:
      NewEntityAst[] = [];

    const placements:
      PlacementAst[] = [];

    const first =
      this.parseNewEntity(
        cursor
      );

    if (!first) {
      throw new Error(
        'CREATE requires an entity'
      );
    }

    entities.push(first);

    let current =
      first;

    let previous =
      first;

    while (
      !cursor.eof()
    ) {
      const word =
        cursor.rawWord();

      // "caixa com um botão"
      if (
        word === 'com'
      ) {
        const checkpoint =
          cursor.index;

        cursor.consume();

        const child =
          this.parseNewEntity(
            cursor
          );

        if (child) {
          entities.push(
            child
          );

          placements.push({
            source: {
              kind:
                'NEW_ENTITY',
              tempId:
                child.tempId
            },

            relationConceptId:
              'C_SPAT_INSIDE',

            target: {
              kind:
                'NEW_ENTITY',
              tempId:
                current.tempId
            }
          });

          previous =
            current;

          current =
            child;

          // "com um botão vermelho dentro"
          if (
            cursor.rawWord() ===
            'dentro'
          ) {
            cursor.consume();
          }

          continue;
        }

        cursor.index =
          checkpoint;

        const mutation =
          this.parseMutation(
            cursor,
            current
              .entityConceptId
          );

        if (mutation) {
          current
            .mutations
            .push(mutation);

          continue;
        }

        break;
      }

      // "uma caixa e um botão"
      if (
        word === 'e'
      ) {
        cursor.consume();

        const sibling =
          this.parseNewEntity(
            cursor
          );

        if (!sibling) {
          break;
        }

        entities.push(
          sibling
        );

        previous =
          current;

        current =
          sibling;

        continue;
      }

      const spatial =
        this.parseSpatial(
          cursor
        );

      if (spatial) {
        // "botão dentro de uma caixa"
        const prefixIndex =
          cursor.index;

        const rawNext =
          cursor.rawWord();

        const targetIsIndefinite =
          rawNext !== null &&
          GRAMMAR
            .indefiniteArticles
            .has(rawNext);

        if (
          targetIsIndefinite
        ) {
          const target =
            this.parseNewEntity(
              cursor
            );

          if (!target) {
            throw new Error(
              'Spatial relation requires target'
            );
          }

          entities.push(
            target
          );

          placements.push({
            source: {
              kind:
                'NEW_ENTITY',
              tempId:
                current.tempId
            },

            relationConceptId:
              spatial.id,

            target: {
              kind:
                'NEW_ENTITY',
              tempId:
                target.tempId
            }
          });

          previous =
            current;

          current =
            target;

          continue;
        }

        cursor.index =
          prefixIndex;

        const target =
          this.parseReference(
            cursor
          );

        placements.push({
          source: {
            kind:
              'NEW_ENTITY',
            tempId:
              current.tempId
          },

          relationConceptId:
            spatial.id,

          target
        });

        continue;
      }

      // "ao lado dela"
      if (
        word === 'ela' ||
        word === 'ele' ||
        word === 'elas' ||
        word === 'eles'
      ) {
        break;
      }

      break;
    }

    return {
      kind: 'CREATE',
      entities,
      placements
    };
  }
```

Ele produz:

```text
  source = tmp_button
  relation = CHILD_OF
  target = tmp_container
```

# 38. ReferenceResolver

```ts
export class ReferenceResolver {
  constructor(
    private document:
      DocumentModel
  ) {}

  resolve(
    reference:
      SemanticReference
  ): DocumentNodeId[] {
    switch (
      reference.kind
    ) {
      case 'CURRENT_SELECTION':
        return [
          ...this.document
            .selectionIds
        ];

      case 'NEW_ENTITY':
        throw new Error(
          'NEW_ENTITY references must be resolved by ExecutionPlanner'
        );

      case 'SELECTOR':
        return this
          .resolveSelector(
            reference.selector
          );
    }
  }

  private resolveSelector(
    selector:
      SemanticSelector
  ): DocumentNodeId[] {
    let nodes =
      Array.from(
        this.document
          .nodes
          .values()
      );

    if (
      selector.entityConceptId
    ) {
      nodes =
        nodes.filter(
          node =>
            node
              .entityConceptId ===
            selector
              .entityConceptId
        );
    }

    if (
      selector.textEquals !==
      undefined
    ) {
      nodes =
        nodes.filter(
          node =>
            node.text ===
            selector.textEquals
        );
    }

    if (
      selector.parent
    ) {
      const parents =
        new Set(
          this.resolveSelector(
            selector.parent
          )
        );

      nodes =
        nodes.filter(
          node =>
            node.parentId !==
              null &&
            parents.has(
              node.parentId
            )
        );
    }

    if (
      selector.direction &&
      nodes.length
    ) {
      nodes =
        this.applyDirection(
          nodes,
          selector.direction
        );
    }

    if (
      selector.exclusions
        ?.length
    ) {
      const excluded =
        new Set<
          DocumentNodeId
        >();

      for (
        const exclusion
        of selector.exclusions
      ) {
        for (
          const id
          of this
            .resolveSelector(
              exclusion
            )
        ) {
          excluded.add(id);
        }
      }

      nodes =
        nodes.filter(
          node =>
            !excluded.has(
              node.id
            )
        );
    }

    if (
      selector.ordinalIndex !==
      undefined
    ) {
      const node =
        nodes[
          selector.ordinalIndex
        ];

      return node
        ? [node.id]
        : [];
    }

    switch (
      selector.quantity?.mode
    ) {
      case 'ALL':
        return nodes.map(
          node => node.id
        );

      case 'COUNT':
        return nodes
          .slice(
            0,
            selector
              .quantity
              .count
          )
          .map(
            node =>
              node.id
          );

      case 'ONE':
      default:
        return nodes[0]
          ? [nodes[0].id]
          : [];
    }
  }

  private applyDirection(
    nodes:
      DocumentNode[],

    direction:
      NonNullable<
        SemanticSelector[
          'direction'
        ]
      >
  ): DocumentNode[] {
    const withRect =
      nodes.filter(
        node =>
          node.rect
      );

    if (
      !withRect.length
    ) {
      return nodes;
    }

    const score = (
      node:
        DocumentNode
    ): number => {
      const rect =
        node.rect!;

      switch (
        direction
      ) {
        case 'LEFTMOST':
          return rect.x;

        case 'RIGHTMOST':
          return -(
            rect.x +
            rect.width
          );

        case 'TOPMOST':
          return rect.y;

        case 'BOTTOMMOST':
          return -(
            rect.y +
            rect.height
          );
      }
    };

    return withRect
      .slice()
      .sort(
        (a, b) =>
          score(a) -
          score(b)
      );
  }
}
```

```ts
export class ConstraintValidator {
  constructor(
    private concepts:
      Record<ConceptId, ConceptNode>,

    private document:
      DocumentModel
  ) {}

  validate(
    plan:
      ExecutionPlan
  ): ExecutionPlan {
    const diagnostics =
      [...plan.diagnostics];

    const tempEntityTypes =
      new Map<
        TempNodeId,
        ConceptId
      >();

    for (
      const step
      of plan.steps
    ) {
      if (
        step.kind ===
        'CREATE_NODE'
      ) {
        tempEntityTypes.set(
          step.tempId,
          step.entityConceptId
        );
      }
    }

    for (
      const step
      of plan.steps
    ) {
      if (
        step.kind ===
        'SET_PROPERTY'
      ) {
        const entityId =
          this.resolveEntityType(
            step.target,
            tempEntityTypes
          );

        if (!entityId) {
          continue;
        }

        const entity =
          this.concepts[
            entityId
          ];

        if (
          entity?.kind !==
          'ENTITY'
        ) {
          continue;
        }

        if (
          !entity
            .capabilities
            .acceptedPropertyIds
            .includes(
              step
                .propertyConceptId
            )
        ) {
          diagnostics.push({
            severity: 'ERROR',

            code:
              'INVALID_PROPERTY_FOR_ENTITY',

            message:
              `${entity.id} does not accept ${step.propertyConceptId}.`
          });
        }
      }

      if (
        step.kind ===
          'PLACE_NODE' ||
        step.kind ===
          'MOVE_NODE'
      ) {
        const relation =
          this.concepts[
            step
              .relationConceptId
          ];

        if (
          relation?.kind !==
          'SPATIAL'
        ) {
          diagnostics.push({
            severity: 'ERROR',

            code:
              'INVALID_SPATIAL_RELATION',

            message:
              `Unknown spatial relation ${step.relationConceptId}.`
          });

          continue;
        }

        if (
          relation.relation ===
          'CHILD_OF'
        ) {
          const childRef =
            step.kind ===
              'PLACE_NODE'
              ? step.source
              : {
                  kind:
                    'NODE' as const,

                  nodeId:
                    step
                      .sourceNodeId
                };

          const childType =
            this.resolveEntityType(
              childRef,
              tempEntityTypes
            );

          const parentType =
            this.resolveEntityType(
              step.target,
              tempEntityTypes
            );

          if (
            childType &&
            parentType
          ) {
            this.validateContainment(
              childType,
              parentType,
              diagnostics
            );
          }
        }
      }
    }

    return {
      ...plan,
      diagnostics
    };
  }

  private resolveEntityType(
    reference:
      ExecutableReference,

    tempEntityTypes:
      Map<
        TempNodeId,
        ConceptId
      >
  ): ConceptId | null {
    if (
      reference.kind ===
      'TEMP'
    ) {
      return (
        tempEntityTypes.get(
          reference.tempId
        ) ?? null
      );
    }

    return (
      this.document
        .nodes
        .get(
          reference.nodeId
        )
        ?.entityConceptId ??
      null
    );
  }

  private validateContainment(
    childConceptId:
      ConceptId,

    parentConceptId:
      ConceptId,

    diagnostics:
      ExecutionPlan[
        'diagnostics'
      ]
  ): void {
    const child =
      this.concepts[
        childConceptId
      ];

    const parent =
      this.concepts[
        parentConceptId
      ];

    if (
      child?.kind !==
        'ENTITY' ||
      parent?.kind !==
        'ENTITY'
    ) {
      return;
    }

    if (
      !parent
        .capabilities
        .canContainChildren
    ) {
      diagnostics.push({
        severity: 'ERROR',

        code:
          'PARENT_CANNOT_CONTAIN',

        message:
          `${parent.id} cannot contain children.`
      });

      return;
    }

    const allowedChildren =
      parent
        .capabilities
        .allowedChildConceptIds;

    if (
      allowedChildren &&
      !allowedChildren
        .includes(
          childConceptId
        )
    ) {
      diagnostics.push({
        severity: 'ERROR',

        code:
          'INVALID_CHILD_TYPE',

        message:
          `${child.id} cannot be inserted into ${parent.id}.`
      });
    }

    const allowedParents =
      child
        .capabilities
        .allowedParentConceptIds;

    if (
      allowedParents &&
      !allowedParents
        .includes(
          parentConceptId
        )
    ) {
      diagnostics.push({
        severity: 'ERROR',

        code:
          'INVALID_PARENT_TYPE',

        message:
          `${parent.id} is not an allowed parent of ${child.id}.`
      });
    }
  }
}
```

```ts
export class ExecutionEngine {
  constructor(
    private concepts:
      Record<ConceptId, ConceptNode>,

    private adapter:
      BuilderRuntimeAdapter
  ) {}

  execute(
    plan:
      ExecutionPlan
  ): {
    success: boolean;

    diagnostics:
      ExecutionPlan[
        'diagnostics'
      ];

    createdNodes:
      Record<
        TempNodeId,
        DocumentNodeId
      >;
  } {
    const fatal =
      plan.diagnostics.some(
        diagnostic =>
          diagnostic.severity ===
          'ERROR'
      );

    if (fatal) {
      return {
        success: false,

        diagnostics:
          plan.diagnostics,

        createdNodes: {}
      };
    }

    const tempMap =
      new Map<
        TempNodeId,
        DocumentNodeId
      >();

    for (
      const step
      of plan.steps
    ) {
      switch (
        step.kind
      ) {
        case 'CREATE_NODE': {
          const nodeId =
            this.adapter
              .createNode({
                entityConceptId:
                  step
                    .entityConceptId,

                text:
                  step.text
              });

          tempMap.set(
            step.tempId,
            nodeId
          );

          break;
        }

        case 'SET_PROPERTY': {
          const nodeId =
            this.resolveExecutableReference(
              step.target,
              tempMap
            );

          const property =
            this.concepts[
              step
                .propertyConceptId
            ];

          if (
            property?.kind !==
            'PROPERTY'
          ) {
            throw new Error(
              `Invalid property ${step.propertyConceptId}`
            );
          }

          this.adapter
            .setProperty({
              nodeId,

              propertyConceptId:
                property.id,

              runtimeProperty:
                property
                  .runtimeProperty,

              value:
                step.value
            });

          break;
        }

        case 'CLEAR_PROPERTY': {
          const nodeId =
            this.resolveExecutableReference(
              step.target,
              tempMap
            );

          const property =
            this.concepts[
              step
                .propertyConceptId
            ];

          if (
            property?.kind !==
            'PROPERTY'
          ) {
            throw new Error(
              `Invalid property ${step.propertyConceptId}`
            );
          }

          this.adapter
            .clearProperty({
              nodeId,

              propertyConceptId:
                property.id,

              runtimeProperty:
                property
                  .runtimeProperty,

              clearValue:
                property
                  .clearValue ??
                null
            });

          break;
        }

        case 'PLACE_NODE': {
          const sourceNodeId =
            this.resolveExecutableReference(
              step.source,
              tempMap
            );

          const targetNodeId =
            this.resolveExecutableReference(
              step.target,
              tempMap
            );

          const relation =
            this.concepts[
              step
                .relationConceptId
            ];

          if (
            relation?.kind !==
            'SPATIAL'
          ) {
            throw new Error(
              `Invalid spatial relation ${step.relationConceptId}`
            );
          }

          this.adapter.place({
            sourceNodeId,

            relation:
              relation.relation,

            targetNodeId
          });

          break;
        }

        case 'DELETE_NODE':
          this.adapter
            .deleteNode(
              step.targetNodeId
            );
          break;

        case 'MOVE_NODE': {
          const targetNodeId =
            this.resolveExecutableReference(
              step.target,
              tempMap
            );

          const relation =
            this.concepts[
              step
                .relationConceptId
            ];

          if (
            relation?.kind !==
            'SPATIAL'
          ) {
            throw new Error(
              `Invalid spatial relation ${step.relationConceptId}`
            );
          }

          this.adapter.place({
            sourceNodeId:
              step.sourceNodeId,

            relation:
              relation.relation,

            targetNodeId
          });

          break;
        }

        case 'QUERY_NODE':
          this.adapter
            .inspectNode(
              step.targetNodeId
            );
          break;
      }
    }

    return {
      success: true,

      diagnostics:
        plan.diagnostics,

      createdNodes:
        Object.fromEntries(
          tempMap
        )
    };
  }

  private resolveExecutableReference(
    reference:
      ExecutableReference,

    tempMap:
      Map<
        TempNodeId,
        DocumentNodeId
      >
  ): DocumentNodeId {
    if (
      reference.kind ===
      'NODE'
    ) {
      return reference.nodeId;
    }

    const resolved =
      tempMap.get(
        reference.tempId
      );

    if (!resolved) {
      throw new Error(
        `Temporary node ${reference.tempId} has not been created`
      );
    }

    return resolved;
  }
}
```

CREATE, UPDATE, DELETE e MOVE não compartilham mais a falsa lógica:

```text
operation → document.createElement()
```

Cada operação gera passos próprios.

# 44. Compilador completo

```ts
export class SemanticCompiler {
  private lexer:
    RawLexer;

  private lexicalIndex:
    LexicalIndex;

  private trie:
    MultiwordTrie;

  private tokenBuilder:
    SemanticTokenBuilder;

  constructor(
    private concepts:
      Record<
        ConceptId,
        ConceptNode
      >,

    lexemes:
      Record<
        LexemeId,
        Lexeme
      >,

    surfaceForms:
      SurfaceForm[],

    multiwords:
      MultiwordEntry[]
  ) {
    this.lexer =
      new RawLexer();

    this.lexicalIndex =
      new LexicalIndex(
        surfaceForms,
        lexemes
      );

    this.trie =
      new MultiwordTrie(
        multiwords
      );

    this.tokenBuilder =
      new SemanticTokenBuilder(
        concepts,
        this.lexicalIndex,
        this.trie
      );
  }

  compileToAst(
    input: string
  ): SemanticDocumentAst {
    const raw =
      this.lexer.lex(
        input
      );

    const grammatical =
      expandContractions(
        raw
      );

    const semanticTokens =
      this.tokenBuilder
        .build(
          grammatical
        );

    const parser =
      new DomainParser(
        this.concepts
      );

    return parser.parse(
      semanticTokens
    );
  }

  compile(
    input: string,

    document:
      DocumentModel
  ): ExecutionPlan {
    const ast =
      this.compileToAst(
        input
      );

    const planner =
      new ExecutionPlanner(
        this.concepts,
        document
      );

    const plan =
      planner.build(
        ast
      );

    const validator =
      new ConstraintValidator(
        this.concepts,
        document
      );

    return validator
      .validate(plan);
  }
}
```

# 48. Formato persistente

A base permanente pode e deve ser JSON.

Exemplo:

```json
{
  "surfaceForms": [
    {
      "id": "SF_BOTAO",
      "rawText": "botão",
      "lexemeId": "LEX_BOTAO",
      "formType": "CANONICAL",
      "morphology": {
        "gender": "MASC",
        "number": "SINGULAR"
      }
    }
  ],

  "lexemes": [
    {
      "id": "LEX_BOTAO",
      "lemma": "botão",
      "pos": "NOUN",
      "senseConceptIds": [
        "C_ENT_BUTTON"
      ]
    }
  ],

  "concepts": [
    {
      "kind": "VALUE",
      "id": "C_VAL_BLUE",
      "valueCategory": "COLOR",
      "literal": "#2563eb"
    }
  ]
}
```

Não entram no JSON:

```text
functions
callbacks
closures
DOM references
Map instances
runtime objects
document nodes
parser state
```

Tudo isso pertence ao código ou ao estado vivo da aplicação.

# 49. Regra final de responsabilidade

```text
DATABASE
    knows facts

LEXER
    knows characters and token boundaries

LEXICAL INDEX
    knows possible words

ONTOLOGY
    knows possible meanings

PARSER
    knows relationships between occurrences

BINDER
    knows property/value compatibility

REFERENCE RESOLVER
    knows which real document node is being mentioned

VALIDATOR
    knows whether the operation is legal

PLANNER
    knows which ordered mutations are required

EXECUTOR
    performs those mutations

RUNTIME ADAPTER
    knows how the builder actually implements them
```

Nenhuma dessas responsabilidades deve voltar a ser fundida em um único `ConceptNode`, `ResolvedFrame` ou scanner linear.
